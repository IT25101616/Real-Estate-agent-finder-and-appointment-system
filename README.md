# Project_08 - Real Estate Agent Finder and Appointment System

Spring Boot backend with simple HTML frontend.

## Run Steps

1. Open project in IntelliJ IDEA.
2. Wait until Maven finishes loading.
3. Create MySQL database if needed:
   `realestate_db`
4. Check `src/main/resources/application.properties` username/password.
5. Run `RealEstateApplication.java`.
6. Open browser:
   `http://localhost:8080`

## Main APIs

- `GET /api/agents`
- `POST /api/agents`
- `GET /api/properties`
- `POST /api/properties`
- `POST /api/appointments`
